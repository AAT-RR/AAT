3. Typical layer stacks

  • Decoupled double wall: mass layers (gypsum, MLV or damping compound) + air gap + fill + sealed door + absorber inside (dB Absorber).
  • Box in a room: outer room walls, air gap, foam insulation, several drywall layers, then the chamber (Shure).
  • Small speaker sound box: birch plywood + rock wool + felt (glued) + interior acoustic foam, about 9.7 cm (UiO).
  • DIY enclosure: double-wall particle board with MLV between, MLV strips for an air gap; seals matter most (auto-pi-lot wiki).
  • Full anechoic room: wedges on all surfaces. Semi-anechoic: reflecting floor, wedges on walls and ceiling (ScienceDirect).

Beamforming, delay-and-sum—Align and sum the channels to favour one direction. MVDR / Capon minimises noise from other directions; superdirective and GSC are variants.
Beam pattern, beamwidth, sidelobedB vs degArray response over angle; main lobe width and level of the other lobes.
Array aperture, spacing dmm, cmLarger aperture gives finer low-frequency resolution; smaller spacing raises the aliasing limit.
Spatial aliasingHzf = c / (2d) for a pair; above it the phase wraps and the direction is ambiguous.
Far field, near fieldmPlane-wave assumption holds in the far field (distance ≫ aperture²/λ); the near field needs spherical wave models.
Microphone mismatchdB, deg, µsSensitivity, phase and delay errors between channels; they become DOA error. See DOA Phase Budget Sim.
Resolution, accuracy, RMS errordegSmallest separable angle; mean error against a known source; spread of repeated estimates.
Speed of sound cm/sAbout 343 m/s at 20 °C; 331.3 + 0.606·T (T in °C).
Sample-rate sync, clock driftppmChannels from different devices drift and shift the phase; array interfaces share one clock.

6.12 Signal processing, adaptive filters and AI / machine-learning terms

General knowledge, not web-sourced. The AAT tools implement NLMS/LMS noise cancellation, spectral subtraction and audio difference extraction; the machine-learning terms are listed for reading papers and vendor sheets.

TermMeaning
LMS, NLMSLeast-mean-squares adaptive filter; NLMS normalises the step size by input power for stable convergence. Step size μ and filter length are the main parameters.
RLS, Kalman filterFaster-converging adaptive filters at higher cost.
ANC, adaptive noise cancellationSubtract a noise estimate predicted from a reference microphone. Needs a reference that has noise but little target signal.
Active noise control (ANC, headphones)Anti-noise played by a loudspeaker (feedforward, feedback, hybrid). Uses FxLMS with a secondary-path model.
AEC, echo cancellationRemove the loudspeaker signal from the microphone signal; ERLE in dB measures the echo reduction.
Spectral subtractionSubtract an estimated noise spectrum from the signal spectrum. Leaves musical noise if over-subtracted.
Wiener filterMinimum-mean-square-error gain per frequency from the signal-to-noise ratio.
VADVoice activity detection: decides speech or no speech, used to update the noise estimate.
Noise suppression / denoisingClassical (spectral subtraction, Wiener, MMSE-LSA) or neural (RNNoise, DeepFilterNet, DNS-style models).
STFT, window, hop sizeShort-time Fourier transform; window length sets frequency resolution, hop sets time step. Hann is a common window.
Spectrogram, mel spectrogram, MFCCTime-frequency picture; mel-scaled version; cepstral coefficients derived from it. Common model inputs.
Cepstrum, LPCSource/filter analysis; linear predictive coding of speech.
Resampling, decimation, anti-alias filterChange the sample rate; low-pass before downsampling.
FIR, IIR, biquadDigital filter types; FIR can be linear-phase, IIR is cheaper. Butterworth, Bessel, Linkwitz–Riley are common alignments.
Machine learning, deep learningModels that learn from data. Training, validation and test sets; overfitting means good on training data only.
CNN, RNN / LSTM / GRU, TransformerCommon network types for audio: convolutional, recurrent, attention-based.
Classification, regression, anomaly detectionTask types. In production audio test: pass/fail classification, level prediction, defect detection from unusual signals.
Features, embeddingsNumbers extracted from audio (spectrum, MFCC, learned vectors) that the model uses.
Accuracy, precision, recall, F1, ROC / AUCClassifier quality. False reject = good unit failed; false accept (escape) = bad unit passed. Production tests care most about escapes.
Confusion matrixTable of predicted against true classes.
Data augmentation, domain shiftCreate varied training data; performance drop when production data differ from training data (new fixture, new site).
Inference latency, quantisation, edge deploymentTime per prediction; reducing model precision to run on small devices.
ASR, WER; TTS; keyword spotting, wake wordSpeech recognition and its word error rate; speech synthesis; always-on detection of a trigger phrase. Test conditions: SNR, distance, accents, device microphone.
PESQ, POLQA, STOI, DNSMOSObjective speech-quality and intelligibility scores (ITU-T P.862, P.863; STOI; model-based DNSMOS). Compare processed with clean reference.
SI-SDR, SDRdB, signal-to-distortion ratio for separation and enhancement.
Source separation, blind source separation, ICASplit mixed sources; independent component analysis separates them without a model of the room.
Dereverberation, WPERemove room reverb; weighted prediction error is the classic method.
